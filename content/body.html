Redactor Feature Highlights

Smart Fill Redaction Mode

"Smart Fill" is now available as a dedicated redaction mode in the export UI, providing visually more pleasing redaction compared to fixed color filling.

Audio Redaction

Redactor supports standalone audio redaction, allowing users to mute, bleep, or remove speech and sensitive information in audio files (without needing video) like MP3, WAV, and AAC.

More Detection Classes

Redactor can now detect these new classes: Documents in general; IDs, e.g. driver licenses or passports; Screens (laptops, monitors, phones). These classes are also selectable via the API.

H.265 Importing

It is now possible to import H.265 (aka HEVC) video files into Redactor. Rendering will still happen i the H.264 format (highest compatibility for video playback)

Undo/Redo Support

Support for such actions via the common [Ctrl]+[Z] (undo) and [Ctrl]+[Y] keyboard input. This covers all areas of editing (boxes, audio regions, grouping).

Background Redaction

Two features were added to make background (aka as reverse) redaction possible: an object can be marked a _As background_, and an object can be marked with the _Keep unredacted_ flag.

Audit Data Generation

For 1+ videos (when not being opened) audit logs can be requested via the context menu. It will yield a ZIP file containing pairs (for each video) of two files.

Product Updates

ALPR+ Capability Brief

Sighthound ALPR+ combines AI-powered object recognition, object tracking, vehicle identification, license plate recognition, and detailed vehicle information in one vehicle analytics platform.

The product page describes ALPR+ as powered by Gen 6 AI and designed for precise vehicle detection, recognition, and analytics across local servers, edge devices, and cloud environments.

For technical buyers, the core differentiation is that ALPR+ is not limited to plate reads: it can return license plate strings and regions alongside vehicle make, model, color, generation, type, and orientation data for integration workflows.

Published ALPR+ Capabilities

License Plate Recognition

Detects license plates, recognizes alphanumeric plate strings, and identifies plate regions; Sighthound states its LPR models can read alphanumeric plates globally, with region recognition documented for US states, Canadian provinces/territories, and European Union countries.

MMCG Vehicle Analytics

Returns vehicle make, model, color, and generation so evaluators can identify vehicles even when the license plate is not visible; Sighthound notes vehicle-recognition models are primarily trained for US, Canada, and EU vehicle markets.

Object Detection

Detects multiple object classes including vehicles, people, faces, cars, trucks, buses, motorbikes, and license plates depending on the API or SIO pipeline configuration.

Object Tracking

Monitors objects across frames in real time; SIO exposes tracker configuration options for stream workflows where tracking is needed and hardware headroom supports the performance cost.

Vehicle Type & Orientation

Determines vehicle type and positioning to support situational awareness beyond a plate string alone.

Structured Vehicle Output

REST and SIO workflows return detailed vehicle and license plate annotations in JSON, including detection coordinates, scores, plate string/region, vehicle color, and make/model/generation fields.

Deployment Modes & Fit

On-Premise

Best for organizations that need to keep video processing inside their own network, control data flow, and manage infrastructure directly.

Cloud

Best for teams that prioritize scalable access, remote management, and centralized API workflows over fully local processing.

Edge Devices

Best when low latency, reduced bandwidth, and processing near the camera are more important than centralizing every frame upstream.

Windows + Linux

Best for buyers that need to align ALPR+ with existing operating-system standards; the product page and SIO docs document Windows and Linux support.

Docker Container

Best for repeatable self-hosted deployments, gateway-based REST API services, model-cache persistence, GPU-enabled hosts, and standard container operations.

Custom Integration
